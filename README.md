# Notchment

Your notch is a drop zone: drag files to the top of the screen and Notchment keeps them in one folder instead of all over your Desktop.

This repository only hosts the releases. Download the latest `Notchment-<version>.dmg` from [Releases](https://github.com/JoelRDev/notchment-releases/releases/latest), open it and drag Notchment to Applications. Installed copies update themselves from here.

Requires macOS 14 or later (Apple Silicon or Intel).
